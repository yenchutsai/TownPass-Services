# Taipei district boundaries

`taipei-districts.json` contains the 12 Taipei City district polygons in WGS84.

- Original provider: Ministry of the Interior / National Land Surveying and Mapping Center (內政部國土測繪中心).
- Original dataset: https://data.gov.tw/dataset/7441
- Source release: `TOWN_MOI_1140318`, 2025-03-18.
- Data license: Government Data Open License, version 1 (政府資料開放授權條款第 1 版), https://data.gov.tw/license
- GeoJSON distribution: https://github.com/plotdb/pdmaptw/releases/download/v2.4.0/town-63000-2025-03-18.geojson
- Distribution manifest: https://github.com/plotdb/pdmaptw/blob/master/manifest.json
- SHA-256 of the downloaded file: `25adc425a49b689f9bae0e6081eba1ecf04d73f157968d7b72e5e4cb6e33a0ad`.

The GeoJSON is a simplified administrative boundary reference, not a cadastral survey. It is bundled locally so district outlines remain available if the online basemap cannot load. Map interactions and layout are implemented independently of the weather reference project.
